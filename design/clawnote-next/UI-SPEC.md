# ClawNote Next UI 方向

## 产品气质

ClawNote 不是后台管理系统，也不是传统文件管理器。它是一块以内容为中心的创作空间：

- 画布优先，应用框架主动退场。
- 内容使用稳定、清晰的纸张表面。
- 玻璃只用于导航、命令、浮层和上下文工具。
- 工具随操作出现，默认不占用创作空间。
- 文档、时间、数据和 Agent 都以可直接操作的对象呈现。

## 视觉令牌

| Token | Value | Usage |
| --- | --- | --- |
| Canvas | `#F5F7FA` | 应用背景 |
| Paper | `#FFFFFF` | 文档和可读内容 |
| Ink | `#15171A` | 主文字 |
| Secondary | `#7A828E` | 次级信息 |
| Hairline | `#D9DFE7` | 分隔线和边界 |
| Accent | `#0A84FF` | 唯一主强调色 |
| Radius small | `8px` | 输入、菜单项 |
| Radius medium | `12px` | 浮层、内容对象 |
| Radius glass | `18-24px` | Dock、命令条、操作条 |

字体优先使用系统字体栈，中文正文 16-17px，行高 1.75；文档标题 38-42px，移动端 30-32px。字距保持 0。

## 玻璃规则

这是 Apple Liquid Glass 的 Web 近似表达，不是 Apple 官方组件：

- 背景透明度约 `70%-82%`。
- `backdrop-filter: blur(20px) saturate(150%)`。
- 1px 半透明白色内高光和冷灰外边界。
- 阴影只表达悬浮关系，不用于正文容器。
- 正文、表格、Diff 和长列表禁止使用透明背景。
- 需要提供无模糊和减少透明度的可访问性降级。

## 空间结构

- 全局 Dock：折叠宽度 56px，悬停或点击展开。
- 命令入口：顶部居中的浮动搜索条，通过 `Cmd/Ctrl + K` 唤起。
- 创作画布：桌面端至少占视口宽度的 80%。
- 文档正文：760-820px，略偏左放置，为右侧边注保留空间。
- 上下文面板：只在选中对象后出现，不常驻。
- 移动端：编辑时隐藏底部主导航，键盘关闭后恢复。

## 页面交互

### 空间首页

最近内容以纸张和实时预览呈现，不使用等宽后台卡片。页面树由 Dock 临时展开，创建动作位于底部浮动操作条。

### 文档编辑

顶部只保留返回、路径、保存状态和协作操作。格式工具跟随选择出现；块操作严格对齐当前文本行。正文在首屏上部开始，不使用封面占位。

### 日历

时间是主要画布。事件是可拖动的时间对象，选中后才打开详情透镜。模式切换悬浮在底部。

### 知识画布

默认用对象和关系组织结构化内容。表格、看板是可切换视图，而不是产品本体。属性面板只在选中对象后出现。

### Agent Studio

Agent、提案和影响目标形成可追踪关系。AI 只能提出变更，用户在统一 Diff 中拒绝、部分接受或接受并创建版本。

### 空间设置

设置通过实时预览直接调整。深层管理选项收起为入口，避免长表单和后台导航。
